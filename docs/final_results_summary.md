## 3. Explicit Data Scope & Context Categorization

1. **Historical Policy Evaluation Metrics:** Derived exclusively from the frozen Step 5F held-out evaluation dataset (2,283 cases).
2. **Demonstration Inference Outputs:** Real-time probability scoring, expected utility calculations, and action selections generated by calling `POST /api/v1/recommend` or `run_batch.py`.
3. **Simulated Recovery Outcomes:** Failure reasons, candidate actions, costs, and recovery outcomes used for model training and policy evaluation are simulated over real transaction metadata from the Olist Brazilian E-Commerce dataset.
